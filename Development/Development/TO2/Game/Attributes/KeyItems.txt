/************************************************************************
**
** K E Y   I T E M S
**
** The KeyItems definitions define all of the attributes associated with
** a particular key item type.
**
** All key item definitions should contain the following properties:
**
**	Name (String)
**
**		User friendly name used in DEdit.
**
**	NameId (Integer)
**
**		Id that maps to the key item name (stored in CRes.dll)
**
**	DescriptionId (Integer)
**
**		Id that maps to the key item description (stored in CRes.dll)
**
**	Image (String)
**
**		Name of the interface image associated with the key item
**
**	Filename (String)
**
**		Name of the model file associated with the key item
**
**	Skin0-N (String)
**
**		Name of the skin file dtx(s) associated with the gear type model.
**      There can be any number of skins: Skin0, Skin1, ..., SkinN
**
**  RenderStyle0-N (String)
**
**		Name of the render style file ltb(s).
**      There can be any number of render styles: RenderStyle0, RenderStyle1, ..., RenderStyleN
**
**	FXName (String)	(OPTIONAL)
**
**		Specifies the optional name of an FxED created FX to create for this key
**		item.  The value of this property MUST correspond to the name of a FX 
**		created using FxED.
**
**  SoundName (String)
**
**      The name of the sound to play when the key item is picked up.
**		(either the absolute path to the sound or the name of the soundbutes.txt
**		sound)
**
*/
