
/*
**
** Name			the name of the attachable. the name is what will be entered into dedit.
** Type			the type of the attachable. the valid types are:
**
**				0 - prop			a static item with no logic, like a hat, or moustache, etc
**				1 - object			an item with logic, like a searchlight, etc
**
** Properties	a string with any object properties you wish to override (for example "Chrome 1;Gravity 0")
** 
** Class		if the type = 1 (object), the class name
**
** Model		if the type = 0 (prop), the name of the .ltb file
**
** Skin0-N		if the type = 0 (prop), the name of the .dtx file
**              There can be any number of skins: Skin0, Skin1, ..., SkinN
**
** RenderStyle0-N 	if the type = 0 (prop), the name of the .ltb file
**					There can be any number of render styles: RenderStyle0, RenderStyle1, ..., RenderStyleN
**
** DeleteOnDeath    1 if the attachment should be deleted when a character dies.
**                  0 if the attachment should be carried over to the body.
**
** DetachWhenShot   1 if the attachment will be detached when shot at.
**		    0 if the attachment should remain attached when shot at.
**
** DebrisType	a string that is the name of a debris in debris.txt that will play if the attachment is shot
**		and DetachWhenShot is 1.	
**
** Translucent	0 or 1 indicating whether or not the model contains translucent parts that need to be sorted
**
*/
