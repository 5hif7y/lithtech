# LithTech Jupiter 69 — Experimental Branch

This is an isolated, experimental branch of the LithTech Jupiter 69 codebase, developed as a test of "vibecoded" development using low-cost AI models.

The main goal of this branch is to explore the modernization of the original codebase by:

* Migrating it to a modern, cross-platform CMake-based toolchain supporting GCC and MSVC.
* Adding direct native Vulkan support, without relying on DXVK or other translation layers.
* Experimenting with large-scale code analysis, refactoring, and restoration using AI-assisted development.

## Project Status

This branch is **experimental and not intended to be considered a clean or authoritative version of LithTech Jupiter 69**.

Because much of the current code was produced through AI-assisted development, the repository may contain:

* Incorrect assumptions and hallucinated implementations.
* Unnecessary or redundant code.
* Inconsistent design decisions.
* Missing or inaccurate documentation.
* Changes that do not faithfully represent the original LithTech architecture.

The current state should therefore be treated as a **research and restoration workspace**, rather than a finished fork.

## Planned Cleanup

The next stage is to:

1. Reconstruct and regenerate accurate technical documentation.
2. Review and clean up the codebase manually.
3. Remove incorrect, speculative, or unnecessary changes.
4. Rewrite and normalize the modified code without relying on AI-generated implementations.
5. Compare the resulting code against the original LithTech Jupiter 69 codebase.
6. Normalize it against the original LithTech Jupiter 69 codebase.

The final goal is to bring the project back as close as possible to the original implementation, while keeping the number of changes to the absolute minimum necessary for the modernization effort.

In other words, this branch is an experimental intermediate step between the original LithTech Jupiter 69 codebase and a cleaner, manually verified modernization.
